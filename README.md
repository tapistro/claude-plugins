# Tapistro Claude plugins

Claude Code plugin marketplace for [Tapistro](https://tapistro.com).

| Plugin | Description |
|--------|-------------|
| [`tapistro`](plugins/tapistro) | Tapistro MCP server plus skills for brand context, AI Agents, journeys, intent, account briefs, outreach and reporting |

```
/plugin marketplace add tapistro/claude-plugins
/plugin install tapistro@tapistro
```

This repository is read-only; it does not accept issues or pull requests.
